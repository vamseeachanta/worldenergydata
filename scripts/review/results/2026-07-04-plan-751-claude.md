## Findings

### MAJOR-1 - Flowing tubing pressure could be fed through shut-in-only correction

Evidence checked by reviewer:

- `src/worldenergydata/modules/state_regulators/colorado_ecmc/facility_detail.py`
  mapped `TUBING_PRESS` to `WHP_flowing_tubing_initial_test`.
- `src/worldenergydata/analysis/underpressured_screen/screen.py` applied static
  gas-column correction to pressure kinds beginning with `WHP_`.
- `config/underpressured_screen.yml` described that correction as shut-in-only.

Required patch:

- Form 5A tubing pressure must stay flowing candidate evidence and must not be
  screen-promoted.
- Only an explicitly reviewed `WHP_shut_in` mapping may use static gas-column
  correction.
- Promotion must include gradient-distribution sanity checks.

### MAJOR-2 - Parser only captured the first Initial Test Data block

Evidence checked by reviewer:

- `facility_detail.py` used a first-match `soup.find()` marker for Initial Test
  Data and first-match regex context extraction.

Required patch:

- Enumerate every Initial Test Data block on each page.
- Pair each block to interval/formation/wellbore context or exclude/count it as
  ambiguous/missing context.

### MINOR findings

- Add fetched-page API/facility identity verification.
- Configure a polite User-Agent and treat 403/404 as terminal non-retryable
  statuses.
- Do not synthesize an API12 default sidetrack suffix.
- Specify the `colorado_ecmc_form5a_v1` adapter contract if an adapter is added.
- Document `near_vacuum` as shut-in-only for Form 5A candidates.
- Make the RED test command assertion-level, not just a collection failure.

## Resolution In Current Plan

The plan was patched to address the two MAJOR findings and the MINOR findings:

- Task 2 now requires User-Agent, terminal 403/404 handling, resume-safe status,
  and rendered page identity checks.
- Task 3 now requires all Initial Test Data blocks to be enumerated and paired
  to completion context or excluded.
- Task 4 now keeps Form 5A output candidate-only by default, blocks flowing
  tubing pressure from screen promotion, forbids static correction unless a
  future reviewed `WHP_shut_in` mapping exists, and defines the optional
  `colorado_ecmc_form5a_v1` adapter contract.
- Task 1 now keeps `api12` null unless a verified sidetrack/API12 source exists.
- The TDD list now includes assertion-level tests for the previously missing
  guardrails.
