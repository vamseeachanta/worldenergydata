## Verdict

MINOR

## Findings

1. Empty or all-bad pressure inputs could produce an opaque missing-column error
   in `build_pressure_observations`.
2. The wells parser's `PRODUCE_FORM` fallback was column-level dead code when
   `FORMATION_AT_TOTAL_DEPTH` existed but was blank.
3. Oracle-style `%b` date parsing was locale-dependent.
4. The Hugoton/Panoma diagnostic county set was narrow and could undercount.

## Disposition

Resolved in the staged implementation after review:

- Added `NORMALIZED_PRESSURE_COLUMNS` and `OBSERVATION_COLUMNS` so empty parser
  and curated outputs preserve schema.
- Added tests for typed empty pressure and observation frames.
- Changed wells formation assignment to per-row fallback from
  `FORMATION_AT_TOTAL_DEPTH` to `PRODUCE_FORM`.
- Replaced locale-dependent date parsing with an explicit Oracle month map.
- Expanded the Hugoton/Panoma diagnostic county set.
