## 1. Purpose and scope

The package downloads NUPRC PDF bytes, extracts blend tables, loads monthly blend records, resolves seed metadata, loads EITI annual production and payments, and computes a PSC fiscal breakdown. [packages/worldenergydata-west_africa/src/worldenergydata/west_africa/nigeria/nuprc_client.py:L85-L96] [packages/worldenergydata-west_africa/src/worldenergydata/west_africa/nigeria/nuprc_client.py:L138-L170] [packages/worldenergydata-west_africa/src/worldenergydata/west_africa/nigeria/blend_production.py:L91-L135] [packages/worldenergydata-west_africa/src/worldenergydata/west_africa/nigeria/field_mapping.py:L122-L186] [packages/worldenergydata-west_africa/src/worldenergydata/west_africa/eiti/country_production.py:L109-L150] [packages/worldenergydata-west_africa/src/worldenergydata/west_africa/eiti/payment_data.py:L144-L176] [packages/worldenergydata-west_africa/src/worldenergydata/west_africa/analysis/field_economics.py:L218-L283]

Scope includes all three subpackages, `nigeria`, `eiti` and `analysis`; their entry docstrings describe these responsibilities. [packages/worldenergydata-west_africa/src/worldenergydata/west_africa/nigeria/__init__.py:L1-L7] [packages/worldenergydata-west_africa/src/worldenergydata/west_africa/eiti/__init__.py:L1-L13] [packages/worldenergydata-west_africa/src/worldenergydata/west_africa/analysis/__init__.py:L1-L7]

Blend totals are stream aggregates rather than uniquely allocated field production; the manual mapping selects dominant metadata and cannot establish field-level allocation. [packages/worldenergydata-west_africa/src/worldenergydata/west_africa/nigeria/field_mapping.py:L2-L6] [packages/worldenergydata-west_africa/src/worldenergydata/west_africa/nigeria/field_mapping.py:L45-L48]

The package metadata declares alpha maturity and Python 3.10 or later; this declaration does not establish live-source coverage or fiscal validity. [packages/worldenergydata-west_africa/pyproject.toml:L10-L22]

## 3. Method and governing standards

| Method | Implementation and reference basis |
| --- | --- |
| HTTP cache / retry | NUPRC hashes the URL; EITI hashes endpoint plus sorted JSON parameters; both use in-memory MD5 keys and retry exceptions, while explicit HTTP errors raise immediately. These are implementation choices, not security digests. [packages/worldenergydata-west_africa/src/worldenergydata/west_africa/nigeria/nuprc_client.py:L82-L135] [packages/worldenergydata-west_africa/src/worldenergydata/west_africa/eiti/eiti_api.py:L72-L135] |
| PDF parsing | `_find_column` uses the first keyword substring in the first row; `_parse_blend_rows_from_table` removes commas, converts to float and supplies no period; `parse_blend_table_from_pdf` concatenates tables/pages. [packages/worldenergydata-west_africa/src/worldenergydata/west_africa/nigeria/nuprc_client.py:L159-L231] |
| Metadata lookup | `lookup_field` uses normalized exact keys; `resolve_blend` tries exact then substring matches and returns a result only for one candidate; `FieldInfo.is_deepwater` uses the code's 300 m threshold. This is a code convention, not a checked standard definition. [packages/worldenergydata-west_africa/src/worldenergydata/west_africa/nigeria/field_mapping.py:L17-L33] [packages/worldenergydata-west_africa/src/worldenergydata/west_africa/nigeria/field_mapping.py:L122-L186] |
| Aggregation | `aggregate_by_blend` sums stored rates by blend; `aggregate_annual_production` sums barrels by country/year; payment aggregators sum USD by company or payment type after an optional year filter. [packages/worldenergydata-west_africa/src/worldenergydata/west_africa/nigeria/blend_production.py:L40-L53] [packages/worldenergydata-west_africa/src/worldenergydata/west_africa/eiti/country_production.py:L60-L76] [packages/worldenergydata-west_africa/src/worldenergydata/west_africa/eiti/payment_data.py:L38-L77] |
| Annual conversion | `ProductionRecord.volume_kbd = volume_bbl / (365 * 1000)`; `cross_validate_nuprc_eiti` uses the inverse conversion with 365 days regardless of year, then computes signed difference and relative percent against EITI. This is the implemented convention, including its zero-denominator limitation. [packages/worldenergydata-west_africa/src/worldenergydata/west_africa/eiti/country_production.py:L20-L21] [packages/worldenergydata-west_africa/src/worldenergydata/west_africa/eiti/country_production.py:L54-L57] [packages/worldenergydata-west_africa/src/worldenergydata/west_africa/eiti/payment_data.py:L100-L115] |
| Fiscal calculation | `calculate_royalty_deepwater` selects a half-open depth band and otherwise returns zero; `calculate_cost_oil_recovery` returns the lesser of expenses and the revenue ceiling; `calculate_profit_oil_split` selects the first production ceiling and splits profit oil. [packages/worldenergydata-west_africa/src/worldenergydata/west_africa/analysis/field_economics.py:L126-L192] |
| PSC composition | `NigeriaDeepwaterPSC.calculate` subtracts royalty before applying cost recovery, floors profit oil and contractor net at zero, takes the maximum of two profit-oil taxes, computes the levy on gross revenue and sums government components. [packages/worldenergydata-west_africa/src/worldenergydata/west_africa/analysis/field_economics.py:L237-L283] |

No legal rate table is reproduced here.
