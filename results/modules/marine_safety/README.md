# Marine Safety Incident Data - CSV Export

## Overview

This directory contains exported CSV files for marine safety incident analysis, providing a lightweight alternative to embedding data in HTML reports.

## Performance Improvement

**Before optimization:**
- hatch_analysis.html: 107 MB (1,031,348 lines)
- Browser performance: Very slow loading, sometimes hanging
- Data embedded: All 191 incident records with full descriptions in JavaScript

**After optimization:**
- hatch_incidents.csv: 90 KB (192 lines including header)
- foundering_incidents.csv: 1.5 MB (8,427 lines)
- fatality_incidents.csv: 2.6 MB (7,313 lines)
- **Total CSV size: ~4 MB** (97% size reduction)
- Browser performance: Fast loading with client-side pagination

## Files

### `hatch_incidents.csv`
- **Records:** 191 detected hatch/door/opening maloperation incidents
- **Size:** 90 KB
- **Columns:** incident_id, date, vessel_name, description, severity, location, source, fatalities, injuries
- **Source:** Pattern-matched from 102,618 total incidents across Canadian TSB, DLP Historical, and IMO GISIS databases

### `foundering_incidents.csv`
- **Records:** 8,426 vessel foundering events
- **Size:** 1.5 MB
- **Columns:** incident_id, date, vessel_name, description, fatalities, location, source, injuries
- **Analysis:** Includes fatality statistics per incident

### `fatality_incidents.csv`
- **Records:** 5,119+ fatal incidents
- **Size:** 2.6 MB
- **Columns:** incident_id, date, vessel_name, description, incident_type, location, source, fatalities, injuries
- **Analysis:** Leading causes of death and accident types

## Data Sources

All data compiled from three major marine safety databases:

1. **Canadian TSB** (Transportation Safety Board): 86,288 occurrences
2. **DLP Historical**: 80,340 accidents (1995-2012)
3. **IMO GISIS**: 13,338 incidents

**Total combined incidents:** 179,966 records

## Usage

### Data Analysis

```python
import pandas as pd

# Load hatch incidents
hatch_df = pd.read_csv('results/modules/marine_safety/hatch_incidents.csv')
print(f"Detected incidents: {len(hatch_df)}")

# Analyze by severity
severity_counts = hatch_df['severity'].value_counts()
print(severity_counts)
```

### HTML Report Integration

The CSV files can be loaded into HTML reports using JavaScript for dynamic, paginated display:

```javascript
// Load data with PapaParse
Papa.parse('../../results/modules/marine_safety/hatch_incidents.csv', {
    download: true,
    header: true,
    complete: function(results) {
        displayIncidents(results.data);
    }
});
```

See `scripts/marine_safety/generate_optimized_report.py` for the complete optimized HTML template.
