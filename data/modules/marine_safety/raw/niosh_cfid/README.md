## Expected Data Schema

Based on Data Liberation Project documentation:

### Tables Expected:
1. **Persons:** Demographics, injury/death details, vessel role
2. **Incidents:** Vessel information, incident type, location, date
3. **Vessels:** Commercial fishing vessel characteristics

### Key Fields:
- Person ID, demographics (age, gender, experience)
- Incident date, location, vessel activity
- Injury/death classification
- Vessel type, length, fishing method
- Contributing factors, causes
- Safety equipment usage
