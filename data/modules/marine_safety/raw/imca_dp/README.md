## Data Access Status

### IMCA DP Incident Database
- **Status:** ⚠️ Restricted Access
- **Coverage:** Dynamic positioning (DP) vessel incidents (2020-2024)
- **Issue:** Detailed incident reports require IMCA membership or purchase
- **Public Data:** Summary statistics available on IMCA website

### What's Available

1. **Free Summary Statistics:**
   - URL: https://www.imca-int.com/safety-events/dp-incident-database/
   - Annual DP incident counts
   - Incident category distributions
   - High-level trend analysis

2. **Detailed Reports (Member/Purchase):**
   - Annual Analysis of Marine Incidents (IMCA SFY-04)
   - Station Keeping Incident Data (IMCA M 220)
   - DP Vessel Incident Reports

## DP Incident Categories

IMCA tracks these incident types:

- **DP System Failures:** Hardware/software malfunctions
- **Human Factors:** Operational errors, training gaps
- **Environmental Conditions:** Weather, sea state impacts
- **Position Loss Events:** Drive-off, drift-off incidents
- **Equipment Failures:** Thrusters, power systems, sensors

## Vessel Types Covered

- **Offshore Support Vessels (OSVs):** Platform supply, anchor handling
- **Drilling Vessels:** Semi-submersibles, drillships
- **Construction Vessels:** Pipelay, heavy lift, crane vessels
- **Cable/Survey Vessels:** ROV support, seismic survey

## Alternative Data Sources

Since IMCA detailed data requires membership:

1. **BSEE Offshore Incidents:**
   - Already have in `/bsee_offshore/`
   - Covers DP vessel incidents in U.S. Gulf of Mexico
   - Includes position loss and collision events

2. **USCG MISLE Database:**
   - Already have in `/uscg_misle/`
   - Includes OSV casualties and machinery failures
   - U.S. territorial waters

3. **EMSA Casualty Reports:**
   - Already have in `/emsa_reports/`
   - European DP vessel incidents included
   - Annual statistics 2020-2023

4. **Norwegian Maritime Authority:**
   - Norway has extensive offshore DP fleet
   - Incident reports available at sdir.no
   - Alternative source for North Sea DP incidents

5. **OCIMF (Oil Companies International Marine Forum):**
   - Marine incident reporting system
   - Some data publicly available
   - Focus on tankers and offshore vessels
