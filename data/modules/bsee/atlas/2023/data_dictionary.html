BSEE Atlas 2023 data dictionary

Source ID: bsee-data-center. Edition 2023; sand data as of January 1, 2024. Source page updated June 16, 2026. CSV headers below are the actual Access table exports; web aliases and Excel headers differ. Source types are obtained with MDB Tools 1.0.0 mdb-schema (PostgreSQL representation).

Identifiers remain strings, including leading zeros in PLAY_NUM/PLAY_NUMBER and WELLAPI. Numeric cells are finite numbers. Empty source cells become null; all source columns are nullable. Access date/time cells exported as YYYY-MM-DD HH:MM:SS (explicit four-digit export) become ISO date/time strings without an invented timezone or century pivot. SN_FORMSAND is numeric in Access but is loaded and cited as a string of nonnegative integer digits; SAND_NAME and CSV row numbers accompany every sand citation.

BOEM_FIELD is the source field code, PLAY_NUM joins to PLAY_NUMBER, CHRONOZONE joins to BOEM_CHRONOZONE. No lease column exists in 2023sands; WELLAPI is a discovery-well identifier, not a lease. BOEM_FIELD is not assumed to be a verified named-field area-block crosswalk.

Derived attribution criteria, version 2

Attribution requires an exact BOEM_FIELD code match plus agreement of a public field name or an independent public lease/block pair, and one consistent play. A block equal to the join code is not a second confirmation; code_match, name_match and lease_block_match record true, false or not-available with the source fields used. Multiple plays or missing/inconsistent lookups remain ambiguous with all candidates; absent sand rows remain unmatched.

The retained 2023xref_oper-comp table supplies lease/block confirmation for Buckskin only; its inconsistent source lookup prevents attribution. The other 89 candidate fields lack independent confirmation in the inspected tables and registry. Canonical IDs resolve through config/fields.yml; unknown IDs remain null.
