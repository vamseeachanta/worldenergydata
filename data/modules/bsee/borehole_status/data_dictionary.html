The loader strips padding but retains cell values as strings; identifiers retain leading zeros. Dates validate as YYYYMMDD. Numeric values validate against their logical types, with finite coordinates bounded to geographic ranges. Empty/whitespace cells stay empty. The source contains ##### in 402 depth cells per depth column and ################ in 402 bottom-coordinate cells per coordinate column. Their cause is not established; masks are preserved and counted explicitly, never converted to numbers.

API12 identifies each borehole; duplicates are rejected. Bottom Lease Number is the field attribution basis. Surface Lease Number is retained independently and never substitutes for a missing bottom lease. All registry fields whose play contains Lower Tertiary are included (11 in this revision). Lease membership does not establish geological targeting, current asset ownership or outstanding P&A liability.

Blank status uses the aggregate key MISSING; a novel status remains under its source code with undocumented_status_code meaning. Missing bottom leases, leases absent from the registry and outside-play registry matches receive distinct reasons. A field without matched boreholes is explicitly marked no_boreholes_on_registered_leases. Status dates are effective dates, not P&A completion dates unless independently established.

BSEE status definitions are paraphrased in schema.json and imported from one code mapping: APD permit-to-drill application; AST approved sidetrack; BP bypass; CNL cancelled after approval; COM completed; CT core test; DRL active drilling; DSI suspended drilling; PA permanently abandoned; ST side tracked; TA temporarily abandoned; VCW volume chamber well. COM is not a producing-well count, ST is not an additional independent well, and these counts are not a cost model.
