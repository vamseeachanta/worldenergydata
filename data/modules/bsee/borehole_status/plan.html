Borehole status curation plan

Refs issue 960. Implementation will proceed under the owner's 2026-10-11 research and data-curation direction.

The public BSEE GoA Borehole delimited ZIP will supply API12, bottom lease, surface lease and borehole status. The headerless 29-column layout will be mapped to documented aliases, with combined location cells explicitly described. Source documentation and downloads will retain UTC retrieval times, byte sizes and SHA-256 digests. Raw files will remain in configurable external storage.

New borehole_status.py and borehole_status_fetch.py package modules, scripts/bsee/fetch_borehole_status.py, borehole_status data artifacts and distinct offline fixtures/tests will be added. Bottom lease will resolve through the existing by_lease registry. Lower Tertiary selection will follow registry play values, including recovered fields. API12 will identify boreholes; no API10 collapse will occur. Unknown leases, missing leases and outside-play matches will remain distinguishable. All selected fields will appear, including fields without boreholes. Status counts will retain blank/unknown codes explicitly and will not imply cost or outstanding liability.

Tests will precede code and will cover documented source rows, malformed widths/API/date/numeric values, duplicate API rejection, variant leases, attribution/count conservation, empty fields, unknown status preservation, polite fetch limits/refusals and provenance readback. Touched code will receive lint/type checks. Source and registry hashes will bind generated output to its inputs.

Open PR file lists will be respected: lease ingest PR 1159 and atlas PR 1155 use separate paths; no shared metadata, registry or panel will change. After both ingests merge, bottom leases will be reconciled with the lease table using normalized identifiers and independent source timestamps. Costs will await owner unit-cost basis; panel replacement will remain downstream work.

Discovery confirms the committed well snapshot has 57,281 rows, no lease column, status/date/company columns and 23 distinct field values including blank (22 nonblank shelf codes). It will not be used as the borehole attribution source.

Sources: download index, layout, status definitions, terms. BSEE warns of database errors, excludes legal-document and navigation use; no explicit licence is stated on the download page.
