# Marine Safety Analysis Reports

This directory contains generated HTML reports from marine safety incident analysis.

## Report Files

HTML reports are generated by running the analysis script and are **not tracked in git** due to their large size (100+ MB).

## Generating Reports

To generate fresh reports, run:

```bash
bash scripts/marine_safety/analyze_incidents.sh
```

This will create the following reports in this directory:

- **executive_summary.html** - Dashboard with key metrics across all incident types
- **hatch_analysis.html** - Detailed hatch/door/opening maloperation incidents (191 incidents)
- **foundering_analysis.html** - Vessel foundering events and fatalities (8,426 incidents)
- **fatality_analysis.html** - Fatal incidents analysis (5,119 incidents)

## Features

All reports include:
- Interactive tables with "View Full Details" modal dialogs
- AI-generated smart summaries extracting key information
- Comprehensive incident data from Canadian TSB, DLP Historical, and IMO GISIS databases
- Severity breakdowns and recommendations

## Analysis Method

The analysis uses:
- **Expanded pattern detection**: 46 regex patterns covering hatches, doors, covers, openings, and hardware failures
- **Real data**: 179,966 marine safety incidents from three major databases
- **Zero-shot classification**: Optional LLM-based detection using facebook/bart-large-mnli

## Quick Start

1. Ensure you have the marine safety module installed:
   ```bash
   uv pip install -e ".[marine-safety]"
   ```

2. Run the analysis:
   ```bash
   bash scripts/marine_safety/analyze_incidents.sh
   ```

3. Open the executive summary in your browser:
   ```
   file:///path/to/worldenergydata/reports/marine_safety/executive_summary.html
   ```

## Report Persistence

Reports are regenerated each time the analysis runs and will overwrite previous versions. To preserve a specific analysis, copy the reports directory with a timestamp or descriptive name.
