Worked example: inputs, method and answer

Inputs are synthetic given values: a subsea tieback with three wells and two manifolds. No field data, cost coefficient or acceptance threshold is used.

Method basis: graph.py, concept_to_graph, _build_subsea and _build_dry_tree, repository revision f82ff2f1 (2026); these are software conventions. Round-robin assignment places trees one and three on manifold one and tree two on manifold two.

The independent count is N = W + M + H + X = 3 + 2 + 1 + 1 = 7 nodes. Production edges equal W + M = 5. Control edges reverse those connections and also total 5. One host-to-export edge gives E = 2(W + M) + 1 = 11. These equations count the specified software topology; they do not size equipment.

A dry-tree input with two wells gives two wellheads, one host and one export: four nodes, two risers and one export edge. A subsea-to-shore input with one well and one manifold gives three nodes and four edges; its terminal is already the export sink. The test docstrings contain each hand calculation.
