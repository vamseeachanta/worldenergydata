Regeneration

PYTHONPATH=src python scripts/field_development/build_na_kika_coulomb_transaction.py
# Optional: --input a cited JSON snapshot; --out a report directory

The generator reads data/modules/offshore_assets/transactions/na_kika_coulomb.json and verifies available local evidence; optional missing or withheld catalogs supply no lifecycle claims. It performs no network requests. It writes and reads back index.html, lifecycle.html, metrics.json, lifecycle.json, economics_readiness.json and provenance.json. Repeated builds from the same input and output location produce identical bytes. Input provenance hashes canonical UTF-8 JSON with indent=2, ensure_ascii=False, allow_nan=False and a trailing newline, with CRLF normalized to LF. Binary input readback is checked against the recorded digest after that normalization; retained-output comparisons apply the same checkout-line-ending normalization. Generated files use LF bytes. Remote-source digests describe original response bytes; catalog receipts hash the exact historical committed bytes without changing catalog files.

Method and worked example

The equations are dimensional definitions derived here, with no empirical coefficient or standard-derived constant: price per reserve unit = consideration [USD] / acquired-interest reserves [boe]; price per flowing unit = consideration [USD] / acquired-interest production [boe/day]. Both observations shall have the same declared consideration basis and acquired-interest asset subject. Each ratio row shows both input observation dates and the consideration effective date. Year-end 2025 reserves post-date the 1 July 2025 effective date by six months; production is the 2026-Q1 average. No date alignment or roll-back is applied. The preparation date is not a production averaging period.

The following synthetic arithmetic example is independent of the public transaction. Its values are invented teaching inputs, not assumed engineering data.

from worldenergydata.field_development.transaction_package import valuation_metrics

def synthetic(value, unit):
    return {
        "value": value, "unit": unit, "basis": "synthetic",
        "subject": "synthetic portfolio", "as_of": "2026-01-01",
        "citation": {"source_id": "hand-calculation", "locator": "worked example"},
    }

result = valuation_metrics(
    synthetic(120, "USD"), synthetic(8, "boe"), synthetic(4, "boe/d")
)
# Independent arithmetic: 120 / 8 = 15.0 USD/boe.
# Independent arithmetic: 120 / 4 = 30.0 USD/(boe/day).
assert result["usd_per_boe"]["value"] == 15
assert result["usd_per_flowing_boe_day"]["value"] == 30

Missing denominators produce a null value with NOT_EVALUATED and a reason. A true zero denominator is separately identified. Invalid units, negative or non-finite values, missing claim locators, and mixed bases or asset subjects are refused. Ratios do not predict investment returns and are not judged against an invented acceptance limit.

Economics refresh contract

A matched block is a candidate lookup key, not a verified field-production join. Before NPV can be evaluated, each field requires a verified field-to-lease/API mapping, dated BSEE monthly production and units, public reserves on the acquired-interest basis, explicit price assumptions, OPEX, CAPEX, fiscal terms, discount rate and decommissioning amount and timing. The present package imports none of those inputs and applies no default values. Its readiness list is the handoff for that refresh.

Validation

Focused tests exercise hand-calculated ratios, mixed-basis and missing-evidence handling, source digests, roster completeness, block-versus-field readiness, escaped HTML, deterministic regeneration and command-line output readback. HTML is self-contained, uses native disclosure controls for evidence inspection and has no external script or stylesheet dependencies. Transaction screening ratios are reported in tables with their inputs and units; field economics remain unevaluated and no time-series chart is supplied; plotting requirements in HTML Reporting Standards apply when a qualified time series is supplied.
