Project component cost traces

The trace combines sanction estimates, contract awards, project statements and revision trails into dated observations. Each observation retains the complete curated source row. It supports evidence inspection; portfolio component-to-total accounting remains NOT_EVALUATED until comparable bases and asset links are established.

Build and inspect

PYTHONPATH=src:packages/worldenergydata-cost/src python scripts/cost/build_project_cost_traces.py \
  --revision 2 --revision-date 2026-10-20 \
  --output-dir "$TMPDIR/project-cost-traces"

The output directory receives project_cost_events.csv, project_cost_events.json, project_cost_traces.html and project_trace_manifest.json. The manifest enumerates the actual project union, per-table row counts, trail-only projects, missing years, SHA-256 digests of every consumed input and output digests. No clock or local path is embedded. Revision and date are supplied explicitly; library calls without them are labelled unissued with no issue date. The same input bytes and revision metadata produce the same output bytes. Existing output files are rejected, so each build requires unused output names. Inputs are read once for parsing and hashing; outputs are read back to verify their digests.

Slices and method

  1. Events: each table has an explicit natural key. Exact duplicate rows collapse; conflicting rows with the same key fail. Content-derived trace IDs do not allocate canonical registry identities. Cross-table corroborating rows remain separate.
  2. Evidence lanes: date precision, native currency when explicitly available, value basis, scope text and provenance remain distinct. Existing controlled award links are checked against project and requirement ownership. Unmapped awards remain unlinked; no development taxonomy or project alias is inferred.
  3. Outputs: the HTML lists events without connecting lines. CSV and JSON preserve raw observations. Exact project coverage and missing years are reported at build time.

Chronology is established only when event A's latest possible date precedes event B's earliest possible date. Sorting overlapping intervals is for display only. Gregorian year/month intervals are used; a year-only observation is not a January publication. SOURCE_PUBLISHED_DATE, when explicitly supplied, is independent of the effective date. ACCESSED_DATE is never substituted. Historical availability indicates only that this date is supplied; it does not qualify the amount for model training.

Missing years = integer years between the first and last observation, minus the observed years. This set operation introduces no estimated values. Separate lanes are keyed by project, total/component, component class, currency, nominal price basis, value basis and scope text. Awards are never accumulated as project spend.

Hand answer: three distinct observations, one missing year (2021). February 2020 ends on February 29. The 2022 annual interval overlaps March 2022, so their chronology is unresolved. Adding a NOK 200 observation creates a separate currency lane; USD 100 and NOK 200 have no meaningful combined amount. A band of 10–20 retains both bounds. An undisclosed award retains blank bounds, rather than zero. Repeating a source row adds no event; changing its amount under the same key raises a conflict.

Source basis and limits

  • Award registry provenance, 2026-07-15: point, band, range, backlog, combined, lease, midstream and not-public semantics. Legacy awards lack structured currency; all such currencies remain unknown, including any import-time conversion. No numeric comparison uses them.
  • Revision trail provenance, 2026-07-15: nominal currency lanes and low confidence for trade-press figures.
  • Trace requirements and accounting contract: no silent FX, deflation, double counting or interpolation.

No fitted coefficients, deflators, monetary conversion factors or acceptance limits are introduced. Total-value fields may contain floors, ceilings or collapsed ranges. Their exact curated scalar text is retained, but bound qualification is NOT_EVALUATED; the original quote is displayed. No scalar is promoted into a validated point. Award bounds qualify only for complete band/range pairs or equal point bounds. Undisclosed, lease, midstream, combined and backlog awards remain NOT_EVALUATED with a reason; their disclosed values and bases are retained. Existing statement rows without confidence remain not_evaluated. Trade-press confidence is capped at low without changing the retained raw row.

Later work requires the portfolio asset-map dependency, structured total bounds, explicit native award currency, ownership/scope and change classifications, and publication dates. Scope changes or basis changes are retained when explicitly classified by the input; they are not inferred from prose. The unavailable v2 asset-map contract is not claimed as verified by this trace manifest. Deflated comparisons, reconciliation residuals and historical model-feature qualification remain outside this build. The existing pilot trace remains unchanged.
