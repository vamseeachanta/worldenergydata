# IRENA offshore wind export loader

Refs [issue 1095](https://github.com/vamseeachanta/worldenergydata/issues/1095).
No energy-mix module existed in the inspected source/package tree. The
`worldenergydata.energy_mix` module provides an offline, country/year table
contract for offshore wind capacity (MW) and generation (GWh).

Search results identified this page; a live listing was not retrieved. No
native export header, file-name pattern, API or download endpoint is asserted.

execution, credential search or workaround followed. `fetch_irena()` and
`python -m worldenergydata.energy_mix fetch` refuse without making requests.
The fetcher was **not exercised against the live source**. The robots probe is
access-refusal evidence, not a successful data fetch.

Licence / terms: **not stated by the source** in the retrieved refusal response.
The terms page and robots policy could not be read. Permission to automate access
or redistribute IRENASTAT data is not established. No IRENA observations or raw
response are redistributed. Only authored synthetic fixtures are committed.
Synthetic provenance marks retrieval time as inapplicable; it does not invent a
retrieval date for observations that were never obtained.

## Input contract

A permitted user-supplied export must first be normalized to UTF-8 CSV with this
exact ordered header. This is a repository schema, not the native IRENA schema.

```text
country,iso_code,year,technology,capacity_mw,generation_gwh,source_url,citation
```

| Column | Rule |
| --- | --- |
| country | Nonempty country/area key; no surrounding whitespace |
| iso_code | Blank if not supplied by the source, otherwise uppercase alpha-3 syntax; never inferred |
| year | Integer from 1960 through the current UTC year; a loader policy, not a claimed source range |
| technology | Exactly `offshore wind` |
| capacity_mw | Finite, nonnegative MW or blank |
| generation_gwh | Finite, nonnegative GWh or blank |
| source_url | Public HTTPS source URL without embedded credentials |
| citation | Nonempty supplied source citation |

At least one measurement per row is required. Blank means unavailable; zero is a
reported zero. Country/year duplicates and inconsistent country-to-code mappings
are rejected. The loader validates code syntax, not membership in an ISO registry.
Units are bound to column names; differently named unit/header columns fail
rather than being silently converted. No country aggregates are inferred.

`load_export(raw_bytes)` returns a tidy list of row dictionaries.
`write_table(records)` validates and serializes the same format. Parsing retains
source URLs and citations; schema validation does not verify source truth or rights.

## Offline use and provenance

The command refuses to overwrite existing output files or the input file.
Output locations are supplied by the caller; there is no machine-specific cache.

```bash
python -m worldenergydata.energy_mix load \
  --input permitted-normalized.csv --output tidy.csv --manifest manifest.json \
  --retrieved-at-utc '2026-10-11T00:00:00Z' \
  --terms-url 'https://example.invalid/replace-with-verified-terms' \
  --terms-quote 'Replace with the exact verified source wording'
```

The timestamp and terms above illustrate parameters and are not source evidence.
Real exports require caller-supplied UTC retrieval time and the exact terms quote
with its page URL. If terms were verified but no terms are stated, supply
`not stated by the source`; this does not establish redistribution permission.
The manifest records source URLs, citations, SHA-256 of the original input bytes,
size in bytes, units, row count, synthetic status and intended-use limitation.
Rights and intended-use eligibility remain independent of format validation.

The committed synthetic manifest is generated by the module without manual edits:

```bash
python -m worldenergydata.energy_mix load \
  --input tests/fixtures/energy_mix/irena_offshore_synthetic.csv \
  --manifest new-synthetic.manifest.json --synthetic
```

The emitter test compares its bytes with the committed manifest. Offline tests
patch URL and socket transports to reject network access. No HTML is generated.

## Remaining evidence

Live offshore wind capacity and generation have not been extracted. A permitted
export and readable current source terms are needed to verify native headers,
country keys, source coverage and reuse rights. Automated fetching will require
an independently verified permitted access method and a successful bounded live
run before any claim that it works.
