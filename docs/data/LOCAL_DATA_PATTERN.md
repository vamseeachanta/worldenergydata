# Local Data Pattern

> Binary datasets too large for git but freely re-downloadable from public APIs.

## Problem

BSEE publishes ~30 datasets as downloadable ZIP files. When converted to pickle
DataFrames, they total ~300 MB of `.bin` files. Storing these in git bloats the
repository and slows clones. Since the data is publicly available, we exclude it
from git and regenerate it locally.

## Pattern

1. **Gitignore**: `data/modules/bsee/bin/**/*.bin` excludes all binary data
2. **Refresh script**: `scripts/refresh_bsee_all.py` downloads and converts all datasets
3. **Graceful degradation**: Loaders return empty DataFrames with a warning when data is missing
4. **Directory placeholders**: `.gitkeep` files preserve the 30-directory structure in git

## First-Time Setup (New Clone / New Machine)

```bash
# 1. Clone the repository
git clone https://github.com/vamseeachanta/worldenergydata.git
cd worldenergydata

# 2. Install dependencies
pip install pandas requests

# 3. Populate BSEE data (~300 MB download, ~8 minutes)
make data
# or: python3 scripts/refresh_bsee_all.py

# 4. Verify data is available
make data-dry
# Should show all directories as "already real data"
```

## Common Operations

```bash
# Full refresh (all 30 directories)
make data

# Dry run — show what would be downloaded
make data-dry

# Refresh a single dataset
python3 scripts/refresh_bsee_all.py --dir platstruc

# Limit download parallelism
python3 scripts/refresh_bsee_all.py --workers 2

# Skip large OGOR-A yearly production data
python3 scripts/refresh_bsee_all.py --skip-ogor
```

## When to Apply This Pattern

Apply to any module where:
- Source data exceeds 100 MB
- Data is publicly and freely re-downloadable
- A deterministic script can regenerate the local copy

Reference: [Data Residence Policy](../../docs/DATA_RESIDENCE_POLICY.md) — Tier 1 (Collection Data)

## What Happens Without Data

Modules that depend on BSEE binary data will still import and run without errors.
Loaders return empty DataFrames and log a warning:

```
WARNING: BSEE data not found: data/modules/bsee/bin/war/mv_war_main.bin.
         Run: python3 scripts/refresh_bsee_all.py
```

Analysis results will be empty until the data is populated.

## Directory Structure

```
data/modules/bsee/bin/
  apichanges/          # API status changes
  apiraw/              # Raw API well list
  approvals/           # Well approvals
  ...                  # (30 directories total)
  rig_fleet/           # Rig fleet inventory
  serialreg/           # Serial registration
  Well_APD_Default/    # Well APD defaults
```

Each directory contains one or more `.bin` pickle files generated by the refresh script.
