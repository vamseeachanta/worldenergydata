Monthly data value checks

The checks below compare computed outputs with independent hand calculations. All input amounts are authored synthetic values. These checks establish arithmetic and unit handling for the stated cases; they do not qualify source observations, data completeness, reservoir pressure or production economics.

Using the monthly helpers

from worldenergydata.australia.monthly_production import total_monthly_gas_mcf
from worldenergydata.eia.monthly_energy import total_monthly_energy_mwh

gas_mcf = total_monthly_gas_mcf([
    {"period": "2024-01", "gas_mmscf": 1.25},
    {"period": "2024-02", "gas_mmscf": 2.50},
])  # 3750.0 Mcf

energy_mwh = total_monthly_energy_mwh([
    {"period": "2024-01", "series": "example", "value": "125.5", "units": "MWh"},
    {"period": "2024-02", "series": "example", "value": "74.25", "units": "MWh"},
])  # 199.75 MWh

The Australia contract requires a single caller-selected gas series with monthly volume in gas_mmscf at common reference conditions. The existing common.units.convert helper supplies the conversion. GBB flow values have unqualified units and cannot be passed through by relabeling them. No public Australian production feed is connected by this helper.

The EIA contract requires one explicit series, unique monthly periods and units="MWh" on every record. API decimal strings and numeric values are supported. API routes with other schemas or unit labels require caller normalization. Power, stock levels and average daily rates are not monthly energy.

Both helpers return the total for the supplied months only. They reject empty input, duplicate or invalid months, missing values, negative values, booleans and nonfinite values, including overflow. A reported zero is retained. Missing months are not filled; a partial series is not established as a complete annual total.

Method and public sources

  • EIA Glossary, Mcf and MMcf entries: thousand and million cubic feet give the scale ratio 10⁶ / 10³ = 1000. Reference temperature and pressure are unchanged.
  • EIA API Technical Documentation, response data and January 2024 v2.1.6 notes: observations can be returned as decimal strings. The monthly helper performs arithmetic addition in one declared energy unit; no energy-equivalence coefficient is used.
  • SENER January 2025 production workbook, Aceite y condensado and Gas Natural units/header rows: Mbd denotes thousand barrels/day; MMpcd denotes million cubic feet/day. The existing loader multiplies average daily rate by 1000 and Gregorian month length. February 2024 has 29 days and March has 31 days.
  • NIST SP 330 (2019), section 3, table 7: giga = 10⁹ and mega = 10⁶, giving 1000 MWh/GWh for the existing generation conversion.

The Kansas check uses the existing module's pressure/depth screening contract. Its pressure includes the module's assumed atmospheric correction; no local atmospheric measurement is established. Wellhead pressure over total depth is not a reservoir pore-pressure gradient. See the pressure-observation method.

Only synthetic rows are added to tests. No source workbook, paid standard, vendor method or large dataset is redistributed. Live data validation and website or explorer pages remain separate work.
