Mexico production chain analysis

Summary

The SENER field-production workbook can be ingested over HTTP without a browser. Monthly petroleum, condensate and gas volumes are normalized with source digests. FDAS input readiness is checked separately from economic viability. Economic viability and development screening remain NOT_EVALUATED until the required contract, forecast and development inputs are supplied.

Source and observed coverage

SENER statistics links to Producción nacional de petróleo y gas natural, enero 2025. The listing and workbook returned HTTP 200 on 2026-10-20. The retained workbook has SHA-256 5dd30d30339e9a73df25d514ccfcde4122605445e4b92d27447b01d34af9e698. The normalized observation contains 210,906 records and 817 field labels, from January 1960 to January 2025. One oil observation is missing; it remains unknown. This historical release is not qualified as current data. Local raw retention and a JSON receipt are supported; backup and publication are separate actions.

Method and units

The workbook sheets are Aceite y condensado and Gas Natural. The source units row defines Mbd as thousand barrels per day and MMpcd as million cubic feet per day. The column headers distinguish petroleum from condensate, and natural gas excluding nitrogen from nitrogen. Thus:

  • Petroleum or condensate (bbl/month) = rate (Mbd) × 1000 × days in month.
  • Gas excluding nitrogen (Mcf/month) = rate (MMpcd) × 1000 × days in month.

The multiplier follows the source units; calendar days come from the Gregorian calendar. There is no gas-to-BOE coefficient and no assumed month length. The published liquids total is not added to petroleum or condensate. Blank values remain unknown, and missing water production is never replaced with zero.

Interfaces

from worldenergydata.mexico_cnh.bulk_client import BulkProductionClient
from worldenergydata.mexico_cnh.chain import run_chain

# Caller-selected operational budgets; these are not engineering constants.
client = BulkProductionClient(timeout=timeout_seconds, max_bytes=download_budget)
download = client.download(output_directory)
result = run_chain(download.workbook, basin=selected_basin, location=selected_location)
report_file.write_text(result.html, encoding="utf-8")

Discovery reads the statistics page and accepts exactly one production XLSX link on the source origin. Multiple candidates require an explicit reviewed URL; media identifiers are not treated as chronological release numbers. HTTPS origin checks also apply before redirects. HTML maintenance responses, oversized responses and schema drift are rejected. The raw file is content addressed; its receipt records URL, retrieval time, digest, source vintage, rows, units and partial readiness. The parser hashes and reads the same byte snapshot.

The existing collection router accepts production_bulk with either workbook for a local file, or directory, timeout, max_bytes and optional url for HTTP acquisition. Unconfigured legacy collection behavior is preserved. Collection errors can still be logged and omitted by the existing router; use continue_on_error=False when failure must propagate.

SenerProductionAdapter implements the shared production contract. It accepts basin/location scoping and preserves field-month provenance in the FDAS bundle. Duplicate source identities are rejected. Ambiguous field labels across basin/location identities require scoping or a reviewed crosswalk. Operator contributions are summed only if every component is known. The existing illustrative Mexico adapter is not automatically replaced.

The executable checks its answer against this independent calculation, retains its synthetic workbook and writes a readiness report. FDAS conversion requires finite, non-negative oil, gas and explicitly supplied field-month water. Supplying water does not qualify a fiscal deck or establish economic viability.

Limitations and way forward

A Mexico fiscal deck is not supplied: a contract-specific royalty, tax and cost-recovery basis was not established from the production workbook. Economic evaluation requires that sourced basis, prices, costs and a forecast; the shared fiscal schema alone does not establish complete Mexico taxation. FieldConcept screening requires water depth, reserves and development metadata. Scheduler registration and the source-refresh acceptance contract remain follow-up work under the Mexico chain issue. No licensed fiscal value or unsourced default is introduced. Tests use synthetic inputs with independent arithmetic and perform no network access.
