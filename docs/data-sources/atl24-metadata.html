Offline reader

src/worldenergydata/field_development/atl24_metadata.py accepts --collections, --granules, --atom and --out paths. It uses the standard library and defusedxml for XML parsing and performs no network requests. JSON output uses UTF-8 and explicit LF newlines on every platform. Supplied byte hashes identify inputs; fixed declared_url fields describe expected queries and do not authenticate input provenance. Reader output always leaves retrieval status UNVERIFIED. Table 1 supplies the separate acquisition receipts for this catalogue revision.

The reader rejects duplicate identifiers, malformed metadata, incorrect collection/version/DOI evidence, and inconsistent granule identities. Ambiguous or invalid Atom size evidence is rejected; absent size stays UNVERIFIED. A mismatched sample requires fresh evidence explicitly selecting the same granule before combination. No collection pagination or acquisition is scheduled.

Focused offline validation on 2026-10-27: 195 tests passed before the newline correction; 196 passed afterward, with one live-network test deselected in each run. The runs used the real package initialization and covered filesystem readback, input preservation, hard-link rejection, calendar validation and XML declaration rejection. The added regression also simulates CRLF text defaults and asserts exact UTF-8/LF output bytes. These counts cover the metadata reader and two terrain test modules, not the full repository suite, live-source access or science-data integration. The five source receipts were not refreshed for this correction.
