Copernicus metocean access migration

The CDS setup guide specifies the current /api endpoint and cdsapi client. Copernicus Marine documents removal of MOTU and its replacement with the Marine Toolbox. The adapters in worldenergydata.metocean.clients.copernicus_clients use these SDKs. Public catalogue checks diagnose service availability without requesting data or loading credentials. Catalogue success does not establish download access.

Inputs and method

check_endpoint(source, timeout=...) accepts era5 or cmems and a required positive finite timeout in seconds. The timeout is an operational input, not a scientific acceptance criterion. A single GET requests the fixed publisher catalogue; redirects are not followed. The method checks the HTTP status, JSON object, expected catalogue identity and type, STAC version presence and nonempty metadata links. Disabled CDS collections fail explicitly. There are no engineering equations, coefficients or limits.

The ERA5 metadata target is the single-levels collection; the Marine target is the Marine Data Store catalogue. CMEMS_BASE_URL remains a compatibility alias for this metadata URL; it is no longer a MOTU download address. Use the SDK adapter for downloads.

HTTP meanings follow RFC 9110 (2022), sections 15.3–15.6, and RFC 6585 (2012), section 4. A missing route alone does not prove retirement. Diagnostic exceptions omit response bodies, redirect locations and underlying transport exception text.

Executable offline worked example

Input: a synthetic metadata response containing the identity and type independently transcribed from the public Marine catalogue. Method: inject that response using HTTPX's mock transport and validate it through the same function used by the live test. Expected answer: MDS. The timeout below is an arbitrary test input; no network request or waiting occurs.

import httpx
from worldenergydata.metocean.clients.copernicus_clients import check_endpoint

payload = {
    "id": "MDS",
    "type": "Catalog",
    "stac_version": "1.0.0",  # Publisher catalogue, accessed 2026-10-19.
    "links": [{"rel": "self", "href": "https://example.org/catalogue"}],
}
transport = httpx.MockTransport(lambda request: httpx.Response(200, json=payload))
answer = check_endpoint("cmems", timeout=1, transport=transport)
assert answer == "MDS"
print(answer)

The contract tests also check the published CDS retrieval example and Marine subset example against fake SDKs. Expected answers are unchanged request arguments and explicit sentinel return values, not fabricated weather results.

SDK configuration and retrieval

Install the optional publisher packages cdsapi and copernicusmarine in the consuming application. They are imported only when their adapters are constructed. Follow the CDS setup guide for the supported client version, external credential configuration and manual dataset terms acceptance. Use publisher-generated selection requests: Era5Client().retrieve(dataset, request, target) forwards the request to cdsapi.Client(url=CDS_API_URL).retrieve.

Follow the Marine migration guide and Python subset tutorial for authentication and dataset selections. CopernicusMarineClient().subset(**selection) forwards the current Toolbox keyword interface. SDKs handle authentication, selection validation and download files. Keep credentials outside source control. Source pages and public catalogues were inspected on 2026-10-19.

Opt-in network smoke tests

With the package and test dependencies installed, set METOCEAN_LIVE_TESTS=1 and supply METOCEAN_LIVE_TIMEOUT_SECONDS, then run:

python -m pytest tests/unit/metocean/test_copernicus_live.py -m network -q

Both tests carry the network marker and skip by default, including offline CI. They check the current public endpoints without credentials. Environment proxy settings are not loaded by the diagnostic client; networks that require a proxy need an explicitly reviewed transport configuration. Failure reports distinguish endpoint changes from access and service failures.

Known limits and later work

Authenticated retrieval, credentials, licence acceptance, downloaded-data readback, scientific qualification and integration into unified gridded queries are NOT_EVALUATED. No default location, time selection or engineering acceptance limit is inferred. Neither SDK adapter implements BaseClient's station-observation interface: these are separate gridded-data request adapters. Independent review is required before merge.
