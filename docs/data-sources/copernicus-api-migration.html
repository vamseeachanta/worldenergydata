Copernicus metocean API migration

Summary

ERA5 requests use the supported CDS SDK at https://cds.climate.copernicus.eu/api. Marine subsets use the Copernicus Marine Toolbox. MOTU services have been removed. Public metadata smoke tests establish catalogue availability and identity only. Authenticated retrieval and engineering suitability are NOT_EVALUATED until credentials, dataset terms, selection and downloaded output are checked.

The current checkout had a MOTU constant but no ERA5 or CMEMS download adapter. The new adapters are available from worldenergydata.metocean.clients.copernicus_clients. They import optional SDKs only on construction. Install the desired SDK into the application environment; importing the module and running offline probes require neither SDK. The retained CMEMS_BASE_URL name now denotes the public metadata catalogue, not a substitute download endpoint. Downloads use CMEMSClient.subset.

Worked example: public metadata input, method and answer

No engineering equation or coefficient is involved. Input is a source identifier; the method reads JSON and compares its identity to the publisher catalogue. The example below runs offline and writes no files. Its response is explicitly synthetic, based on the public catalogue schema; it is not observed metocean data.

import httpx
from worldenergydata.metocean.clients.copernicus_clients import probe_catalogue

# Source: https://stac.marine.copernicus.eu/metadata/catalog.stac.json
transport = httpx.MockTransport(lambda request: httpx.Response(
    httpx.codes.OK, json={"id": "MDS", "type": "Catalog", "links": []}
))
with httpx.Client(transport=transport) as http:
    answer = probe_catalogue("cmems", http=http)
assert answer["id"] == "MDS"
print(answer["id"])  # MDS: the expected catalogue identity; no download verdict.

Download usage

Install worldenergydata-metocean[copernicus] for the optional SDKs. Configure credentials only through CDSAPI_KEY or both COPERNICUSMARINE_SERVICE_USERNAME and COPERNICUSMARINE_SERVICE_PASSWORD. The adapters require these environment variables and do not fall back to stored credential files. SDK exception details are suppressed; keep SDK debug logging disabled. See the endpoint audit for access requirements and credentialed tests. Never place tokens or passwords in source, examples or reports. Accept CDS dataset terms through its download form first. Copy the current dataset request from that form, then pass it as ERA5Client().retrieve(dataset, request, target). For Marine, pass the current dataset ID and the tutorial's selection arguments as CMEMSClient().subset(dataset_id, **selection). The SDK manages transport, authentication, discovery and file output. Return values are the SDK's own values. These wrappers do not normalize observations, convert units or qualify engineering inputs.

The live checks send no credentials, follow no redirects and download no observations. Missing or gone endpoints fail as “retired or moved”; this is a diagnostic, not proof of retirement. Authentication, transport, rate-limit and server errors are reported separately. HTML, wrong identities and malformed catalogue schemas also fail. Response bodies and underlying transport exception text are excluded from diagnostics.
