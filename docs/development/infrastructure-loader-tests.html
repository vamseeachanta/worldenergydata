Infrastructure loader verification example

Draft for maintainer review

1. Executive summary

The infrastructure loader is a local reader of platform and pipeline tables. Analysis is performed to determine whether file selection, caching and filtering preserve the specified rows; key results are summarized below.

  • Reproduce the expected row selection using the synthetic example.
    • Compare the selected labels against the complete input table.
  • Automated characterization: 58 passed on Linux with Python 3.11.14, pandas 2.3.3 and NumPy 2.3.3.
    • Both platform_loader.py and pipeline_loader.py reach 100 % line and branch coverage using the path-based command in section 9.2.

2. Basis and criteria

The implemented reader predicates are used as the behavioral basis. Exact equality of values, columns, row indices and data types is required for the selected synthetic table.

Area and block conditions are combined with logical AND. Block, complex and lease query arguments are converted to strings; stored columns are not normalized. Status is compared directly. No physical equations, dimensional coefficients or engineering acceptance limits are used.

3. Inputs

Synthetic labels are used to isolate each predicate. The input register is provided in the appendix; no field measurements are represented.

Only temporary pickle files produced from these fixtures are consumed. Pickle is intended here for trusted test-generated objects; this example provides no qualification of externally supplied pickle files.

4. Method

Files with the binary suffix are read from the selected directory. DataFrames are concatenated with a fresh row index, while other deserialized objects are ignored.

A successful table is cached. Later configuration changes do not replace that cache. Permit and location tables have separate caches.

5. Worked selection

The platform query is evaluated for area EI and block 330. Each appendix row is compared independently.

The label “match” satisfies both conditions. The label “other_area” fails the area condition, and “other_block” fails the block condition. The returned label list is [“match”].

For complex 330, the returned labels are [“match”, “other_area”]. For lease 330, the returned labels are [“match”, “other_block”]. For pipeline status ACT, the returned labels are [“match”, “other_area”]. These answers are derived by direct comparison with the appendix, without a calculation library.

6. Error and boundary behavior

Missing directories, empty directories and files containing no DataFrame return no table. A read error also returns no table and leaves the cache unset.

An empty DataFrame is a successfully cached table, but its public queries return no result. A corrupt file following a valid file prevents publication of a partial cache. Directory enumeration order is not specified, so concatenation checks compare sorted complete rows while separately checking the fresh index.

7. Validation and pre-flight checklist

Execution on Linux with Python 3.11.14, pandas 2.3.3 and NumPy 2.3.3 gives 58 passed. Path-based measurement gives 100 % line and branch coverage for platform_loader.py and pipeline_loader.py; the directory total also includes the router and is not the loader acceptance criterion.

  • Input provenance: synthetic values explicitly declared; no measured values or engineering constants.
  • Expected answers: derived from explicit equality predicates and full-table comparisons.
  • Isolation: the data resolver is replaced with a temporary directory before construction.
  • Production changes: none.
  • Execution: 58 passed using the no-conftest route and the path-based coverage command in section 9.2.
  • Presentation: ten numbered sections and revision history, captions below objects, source locators in section 9.2.
  • Physical charts and geometry: not applicable to table-reader behavior.
  • Comment persistence: a save control is provided; browser interaction is not verified.

8. Disposition

The example establishes a hand-checkable expected selection. All 58 characterization cases pass; platform_loader.py and pipeline_loader.py each reach 100 % line and branch coverage in the stated environment.

The automated result meets the exact-row comparison criterion for the synthetic inputs. Changes to cache invalidation, schema validation and exception policy remain outside this characterization; externally supplied data and browser comment persistence are not qualified by these tests.

With the repository packages and test dependencies available, execute from the repository root; direct temporary output to a new disposable directory:

python -m pytest tests/unit/bsee/data/loaders/test_infrastructure_loaders.py --noconftest -q -o addopts=--strict-markers -p no:cacheprovider --basetemp TEMP_DIRECTORY
