Proposed contract

Backend api
from metocean_api.ts import TimeSeries; construct with explicit parameters; import_data mutates self.data and has no explicit return value. Do not treat its return as a FetchResult.
Failure behavior
Missing rights, metadata, digest match, API declaration, grid identity or units keeps the source BLOCKED. Do not enable fetches from this report. Future implementation must reject ambiguous selections, preserve partial-fetch errors, avoid silent fallback or invented values, and retain content-addressed evidence outside the checkout.
Local result
Propose FetchResult.data as explicit model-grid records, source as a separately reviewed source identity, fetch_time as retrieval UTC, records_count=len(data), and explicit had_errors/error_messages. No existing enum value should disguise a new product.
Query
Require explicit supported dataset/product, longitude, latitude, start/end UTC, variables and relevant height/depth. Reject unsupported identifiers before any I/O. Bound selection to the actual regional footprint.
Station boundary
BaseClient.fetch_historical expects station_id and datetimes, while upstream takes lon/lat and string times. A deterministic grid-point identifier and separate hindcast model record are unresolved. fetch_stations and fetch_realtime must explicitly reject unsupported operations rather than invent stations or forecasts.
Status
PROPOSED; no production contract or adapter added.
