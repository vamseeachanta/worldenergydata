Sample query and reproducible checks

The retained lease query selects G16942, returns status PROD and effective date 1996-09-01, and resolves through by_lease. It checks a local BSEE snapshot, without a BOEM network request.

import json
from pathlib import Path
from worldenergydata.common.fields_registry import load_fields

root = Path.cwd()
rows = json.loads((root / "data/modules/bsee/leases/leases.json").read_text())
row = next(item for item in rows if item["lease_num"] == "G16942")
assert (row["status"], row["effective_date"]) == ("PROD", "1996-09-01")
assert load_fields(root / "config/fields.yml").by_lease(row["lease_num"]) is not None

Run from the repository root in Bash on Linux, with TMPDIR set to an existing writable temporary directory. Set the root, core and BSEE source directories on PYTHONPATH as shown. Known limits and way forward

  • Direct BOEM ingestion, complete offshore coverage and current-source freshness remain unverified. Existing BSEE results cannot substitute for these criteria without an explicit scope decision.
  • The legacy downloader declares a BOEM lessee-record URL in packages/worldenergydata-bsee/src/worldenergydata/bsee/paleowells/data_downloader.py. A declared URL is not evidence of retained data, successful ingestion or catalog resolution. No downloader is executed by this review.
  • Missing binary-store paths are observations of this checkout. They do not prove the datasets are unavailable elsewhere. No external data location is inspected.
  • No package is modified. The silent-failure sweep has zero changed modules to inspect; existing ingestion defaults and error handling are not qualified by this report.
  • Issue 124 should remain open pending a scoped follow-up: establish the intended BOEM sources and acceptance counts, restore or ingest missing platform-permit artifacts, and connect retained datasets to catalogs with a successful native sample query. No new pipeline or catalog rewrite is authorized by this verification-only plan.
