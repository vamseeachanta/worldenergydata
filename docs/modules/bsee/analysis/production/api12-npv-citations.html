API12 NPV with explicit royalty evidence

The existing API12 scalar calculation uses FDAS discounting, WTI-derived gross revenue and assumptions-manager costs. The optional calculate_npv_with_citations method deducts a caller-supplied royalty fraction and emits its citation beside the numeric NPV. Without that input, the original gross result is returned with royalty marked NOT_EVALUATED.

Method and source basis

For period t, royalty is gross oil revenue multiplied by the supplied fraction. Operating cashflow is gross revenue less royalty and volume multiplied by unit operating cost. Capital expenditure occurs at inception. These are accounting definitions; the royalty fraction is a required input rather than a statutory default.

CF[0] = -CAPEX
CF[t] = gross_revenue[t] * (1 - royalty_rate) - production[t] * OPEX
NPV = sum(CF[t] / (1 + r_period)**t)
r_month = (1 + r_annual)**(1/12) - 1

The NPV reference is OpenStax, Principles of Finance (2022), Section 16.2, Net Present Value Method. The implemented discounting source is the repository's FDAS financial module (2025 implementation), calculate_npv in packages/worldenergydata-fdas/src/worldenergydata/fdas/core/financial.py. The twelve-period conversion is the calendar convention for monthly cashflows. The citation identity and direct-resolution method follow the calculation-output citation contract v1 (2026). Costs and discount rates continue to resolve through AssumptionsManager, including existing configuration overrides.

The hand calculation is -1000 + 675/1.1 + 2225/1.1² = 175750/121 USD, which rounds to 1452.5 USD. The gross calculation without royalty is -1000 + 800/1.1 + 2600/1.1² = 227000/121 USD, or 1876.0 USD. Royalty reduces NPV by 423.6 USD. The difference is evaluated before rounding. Neither result qualifies an actual lease or includes tax, royalty relief, gas revenue or abandonment costs.

Executable example

The example creates only synthetic evidence in a temporary directory. The regression test independently checks its answer as an exact rational number.

from pathlib import Path
from tempfile import TemporaryDirectory

import pandas as pd

from worldenergydata.bsee.analysis.production_api12 import ProductionAPI12Analysis
from worldenergydata.fdas.core.citations import Citation, CitedRoyalty

cfg = {"economics": {"cost": {
    "CAPEX": 1000, "OPEX": 2, "discount_rate_annual": 0.1
}}}
revenue = pd.DataFrame({
    "Month": ["Period 1", "Period 2"],
    "Monthly Oil Production": [100, 200],
    "Revenue (USD)": [1000, 3000],
})
with TemporaryDirectory() as folder:
    root = Path(folder)
    relative = "wikis/engineering/standards/example.md"
    page = root / relative
    page.parent.mkdir(parents=True)
    page.write_text(
        "---\ncode_id: SYNTHETIC-ROYALTY\npublisher: Synthetic example\n"
        'revision: "1"\nsource_sibling: generic\nroyalty_rate: 0.125\n'
        "---\nAssumed worked-example fraction: one eighth.\n",
        encoding="utf-8",
    )
    royalty = CitedRoyalty(rate=1 / 8, citation=Citation(
        code_id="SYNTHETIC-ROYALTY", publisher="Synthetic example",
        revision="1", section="Worked example", wiki_path=relative,
    ))
    result = ProductionAPI12Analysis().calculate_npv_with_citations(
        cfg, revenue, period="annual", royalty=royalty, wiki_root=root
    )
    print(f"NPV: {result['npv']:.1f} USD; royalty: {result['royalty_status']}")
# NPV: 1452.5 USD; royalty: EVALUATED

Evidence and compatibility boundary

The explicit wiki root contains the relative wikis/ tree. Frontmatter shall match code_id, publisher, revision, source_sibling and optional source_project; a numeric royalty_rate shall equal the input fraction. Missing files, metadata mismatches, ambiguous YAML, nonfinite fractions, source pages and paths escaping the root cause CitationResolutionError before calculation. Invalid input records raise ValueError or TypeError. An explicitly evidenced zero fraction is EVALUATED; absent evidence is NOT_EVALUATED, with a null rate and empty citation list.

Matching metadata establishes that the supplied fraction agrees with the selected page. It does not establish the source's legal applicability, freshness, lease terms, valuation adjustments or royalty relief. Those require source review. No universal federal royalty rate is introduced. Public reference retrieval did not provide usable source content, so no statutory numeric value is qualified by this example.

The original calculate_npv and compatibility wrappers return unchanged scalar results. The sidecar API expects gross oil revenue; passing already-net revenue would deduct royalty twice. Missing or nonfinite gross revenue and production are rejected in the cited path. The period argument defines equal cashflow spacing; date labels are not used to infer elapsed time. The general citation rollout remains tracked separately in issue 361; issue 367 remains open for qualified lease evidence. No archived calculator is imported or reinstated.

The executable regression suites are tests/unit/bsee/analysis/test_production_api12_royalty.py and tests/unit/fdas/core/test_citations.py.
