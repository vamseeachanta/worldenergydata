Completion and intervention area characterisation

Summary

The analysis now counts supplied completion, EOR and WAR records by year, bottom-hole area and raw status or activity code. The charts below describe the retained public-source test fixtures only. They do not measure regional activity, temporal trends or intervention rates.

Method and source basis

For each year/area/raw-code group g, n(g) = sum of the indicators that a record belongs to g. This is the frequency-count construction in NIST/SEMATECH e-Handbook, section 1.3.3.14, Histogram (accessed 2026-10-19), applied to categorical groups. No coefficient, design limit, duration conversion or acceptance threshold is introduced.

WAR uses WAR_START_DT; EOR uses BOREHOLE_STAT_DT, which is not an intervention event date. Completion uses COMPLETION_DATE. Missing or invalid dates remain in an unknown-year group. WAR and EOR retain each report's BOTM_AREA_CODE. Completion areas require a unique nonblank BOTM_AREA_CODE for the API in the borehole snapshot; missing, unmatched and conflicting attribution remains unknown. No report-area fallback is applied.

Each report key is counted once after exact-duplicate removal; conflicting report areas are rejected. Repeated completion rows remain source rows and do not establish separate installations. Distinct API counts apply within each group; they are not additive across groups.

The fixture source manifest records row counts, archive digests, projection digests and official source addresses. Original archive retrieval dates and source identifiers remain in the existing criteria. The source families are BSEE WAR, BSEE EOR, BSEE API Lookup and BSEE Borehole.

Data coverage and gaps

All plotted fixture records have an area attribution under the stated basis. This does not establish full-source coverage. The original retained projections omit operator-class definitions and dated operator attribution: operator-class counts are NOT_EVALUATED, with null counts rather than a true zero. A sourced class mapping and dated attribution are required before this breakdown can be calculated.

The original full-archive report and its manifest remain at their issued revision; this change does not regenerate them. Full-source area trends are not established by these small fixtures. Area metadata is not a reconstruction of historical well locations.

WAR records are reports rather than separate interventions; EOR status dates do not establish event years. Raw codes retain the canonical vocabulary's meaning provenance. Rates, durations, well-age correlations and engineering performance comparisons remain outside this count-only analysis under the duration-basis work (issue 1063).

Verification and next step

The note's plotted counts are checked against an independent CSV-and-set tally in the characterisation tests. Synthetic hand tallies also test duplicate handling, ambiguity, missing values and reconciliation. The next analysis step is to rebuild from verified full archives, then supply a sourced operator-class mapping; neither can be inferred from the fixture charts.
