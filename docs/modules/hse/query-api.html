HSE Python query API

The five query surfaces return pandas DataFrames. Configured queries read an existing SQLite database, apply bound SQL predicates and never fall back to demonstration records. No engineering qualification or dataset completeness is established by a successful query.

Connection and result contract

import os
import worldenergydata as wed

config = wed.hse_api.HSEQueryConfig(database_url=os.environ["HSE_DATABASE_URL"])
with wed.hse_api.HSEApi(config) as client:
    incidents = client.incidents.query(operator="Example A", year=2024,
                                       severity="fatality", source="bsee_inc")
    penalties = client.penalties.query(year=2024, min_amount=20)
    totals = client.statistics.query(year=2024, metric="total_incidents",
                                     grouping="operator")
    releases = client.epa_tri.query(naics="111", year=2024)
    osha = client.osha.query(severity="fatality", year=2024)

The operator and industry examples are synthetic inputs. Configuration is a frozen Pydantic model. Missing files, missing tables and invalid filters raise errors. Unknown keyword arguments are rejected. Singular and plural filters are supported; a nonempty plural list takes precedence. Filters combine with AND; values within a plural list combine with OR. Year bounds are inclusive and a single year takes precedence over the bounds. Exact strings are case-sensitive.

limit and offset paginate after filtering and aggregation. Rows are ordered by primary key; grouped statistics are ordered by the grouping column. Empty results retain their selected columns. Frames carry attrs["data_kind"] and attrs["workflow_id"]. Module singletons retain the compatibility sample with data_kind="synthetic". That metadata does not certify injected data or survive every serialization.

Surface semantics

SurfaceSelectionLimits
incidentsoperator, incident_type, severity, field, source, year Source is inferred from the importer identifier convention: OSHA-prefixed identifiers select OSHA; other identifiers select bsee_inc. This is not independent source provenance.
penaltiesoperator, penalty_status, year, min_amount Year is the parent incident year. Amounts use the stored currency basis; no currency conversion or assessed-versus-proposed reconciliation is applied.

Asynchronous queries

async def read_incidents(config):
    async with wed.hse_api.HSEApi(config) as client:
        return await client.incidents.aquery(year=2024)

The database package declares aiosqlite and SQLAlchemy's asyncio dependencies. Both methods build the same SQL statement. One async engine is shared per client, with a separate session for every query, including concurrent calls. Pool size and overflow are configurable resource settings. The async context disposes both engines; the synchronous context releases the synchronous engine. Use a client within one event loop and use the async context whenever aquery is called. Injected synchronous sessions remain caller-owned.

Command line

worldenergydata hse incidents query --operator "Example A" --year 2024 --output json
# Set HSE_DATABASE_URL to an existing SQLite database before this command.
# Alternatively, supply --database-url explicitly.
worldenergydata hse incidents query --demo --year 2022 --output json

The command supports JSON and CSV. Demonstration selection is explicit and is labeled on standard error; standard output contains the records.

Worked example and method

The runnable quickstart uses the existing synthetic fixture: penalty amounts 5000, 15000 and 50000. The minimum-10000 predicate excludes 5000. The independent sum is 15000 + 50000 = 65000. These are invented software inputs, not published measurements or acceptance limits. The method is selection followed by addition; no physical equation or standards-derived coefficient is used.
