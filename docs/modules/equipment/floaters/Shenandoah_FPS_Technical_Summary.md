# Shenandoah FPS - Technical Summary

## Project Overview

**Project Name:** Shenandoah Floating Production System (FPS)  
**Operator:** Beacon Offshore Energy LLC  
**Location:** Walker Ridge Blocks 51, 52, and 53, Gulf of Mexico  
**Distance from Shore:** ~150-160 miles off the coast of Louisiana, ~230 miles from New Orleans  
**Water Depth:** 5,500-5,800 feet (1,700-1,900 meters)  
**Field Type:** Ultra-high-pressure oil and gas development  
**Reservoir Depth:** ~30,000 feet true vertical depth  
**Pressure Rating:** 20,000 psi (industry-leading high-pressure technology)  
**FID Date:** August 27, 2021  
**First Oil:** July 2025 (Q2 2025)  
**Target Production Rate:** 100,000 bopd / 117,000 boepd achieved within 75 days  

## Ownership Structure

- **Beacon Offshore Energy:** 20.05% (Operator)
- **BOE II Exploration:** 10.95% (Blackstone Group portfolio company)
- **ShenHai (Navitas Petroleum):** 49%

## Technical Design Features

### Hull Design (OPTI-11000)

**Key Features:**
- Four-column semi-submersible with ring pontoon configuration
- Single deck truss connecting column tops
- Patented "lip" configuration (pontoon in front of column placement)
- Square columns with rounded corners for easier fabrication
- Optimized for heave motion cancellation
- Deep draft design for improved motion characteristics

**Advantages:**
- Standardized, repeatable design for fast-track execution
- Lower-risk quayside integration (vs. offshore lift)
- Single-deck design facilitates construction flexibility
- High deck-to-hull steel weight ratio (2.0-2.5)
- Suitable for water depths up to 10,000 feet
- Proven design (Delta House, King's Quay, Shenandoah)

### Power Generation

- **Primary:** Three 4160-V turbine-driven generators
- **Backup:** Diesel generators for black-start capability

### Riser System

- **Configuration:** Dual flowlines and risers
- **Attachment:** Bottom-tensioned risers (weight-saving feature)
- **Subsea Manifold:** Connecting four production wells

### Mooring System

- **Type:** Catenary mooring with OVT BarLatch system
- **Mooring Piles:** Installation completed prior to FPS arrival
- **Technology:** Off-vessel tensioning to save topsides weight and space

## Design Philosophy & Legacy

### Standardization Approach

The OPTI-11000 design represents a "design one, build many" philosophy:

1. **Who Dat FPS** (OPTI-EX) - First deployment, 2011
2. **Delta House FPS** (OPTI-11000) - Second deployment, 2015
3. **King's Quay FPS** (OPTI-11750) - Third deployment, 2022
4. **Shenandoah FPS** (OPTI-11000) - Fourth deployment, 2025

Each successive platform incorporates lessons learned while maintaining the core standardized design for rapid deployment and cost efficiency.

### Key Success Factors

- **Quayside Integration:** Single-lift topsides installation reduces offshore risk
- **Simplified Processing:** Lean topsides design with automation reduces manning
- **Standardization:** Proven hull design accelerates engineering and construction
- **Flexibility:** Single-deck design allows late equipment deliveries
- **Efficiency:** High production-to-weight ratio maximizes value
