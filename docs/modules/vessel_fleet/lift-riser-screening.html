Lift-riser design-basis template and flow screens

Generic public-source code in worldenergydata.vessel_fleet, beside the existing riser models. No equipment record, empirical calibration dataset or qualified design is supplied. Scope follows the public riser issue and the merged model layout.

Screening only. Successful validation establishes required fields and mathematical consistency. It does not establish source truth, correlation applicability, code compliance, structural adequacy or deep-sea transport capacity. Numeric domains are caller-attested; source URLs are not fetched or authenticated. No network or solver is used by these modules.

Every physical scalar uses {"value": ..., "unit": ..., "source": ...}. Units must match exactly; no automatic conversion is performed. Evidence should identify a stable document reference, revision, locator, datum, condition and intended use. Missing input is None in the worksheet, not zero. The completed model requires finite numbers and nonblank evidence.

Both operating and survival cases are required. Each retains strength/stability, fatigue/vibration, transport/pressure-transient, pump/shutdown and motion/clearance check categories with caller-supplied criterion references. These are review tasks, not passed checks. Additional check categories are allowed; duplicate names and omitted baseline categories are rejected. Category selection is template organization informed by S5 and S6, not a standards-derived completeness claim.

One common environment/motion envelope is referenced by both cases. Different case envelopes require separate basis records. Equivalent string/pump properties refer to distributed schedules and performance curves. Auxiliary geometry uses SI inputs; it is not silently converted from the existing catalog's inch fields. No catalog values or material grades are imported. Installation, blockage, emergency disconnect, shutdown transients, detailed buoyancy, corrosion, erosion and coupled response require further definition.

Flow screening interfaces

Import from worldenergydata.vessel_fleet.lift_flow_screening. Every function requires a Calibration(model, source_url, source_locator, conditions, ranges). The ranges mapping contains an Interval(lower, upper) for every numeric argument under its exact SI name. Settling also requires particle_reynolds. Extra/missing fields, nonfinite bounds, reversed intervals, out-of-domain inputs and a mismatched model discriminator are rejected. Inclusive point domains are valid for a single sourced condition. No default gravity, density, viscosity, empirical coefficient or limit is used.

Function / modelRelation and returnRequired applicability and rejection
settling_velocity_m_s
isolated_sphere		w = sqrt(4 g d (rho_s/rho_l - 1)/(3 Cd)); m/s S1. Heavier isolated sphere in Newtonian liquid. Required Cd and its Reynolds domain must match the computed Re = rho_l w d / mu. No hindered settling, particle interaction or wall correction.
critical_deposition_velocity_m_s
horizontal_slurry		v = FL sqrt(2 g D (rho_s/rho_l - 1)); m/s S2. Horizontal transport only. Required FL and evidence must cover pipe/particle diameters, fluid properties, concentration and size distribution. Reject d >= D or rho_s <= rho_l. Operation needs a separately established margin above the threshold. This is not a vertical limit.
minimum_vertical_velocity_m_s
vertical_slip		j = (1-C) w + required v_s; m/s Continuity and phase-slip identity: j = (1-C) v_l + C v_s, w = v_l - v_s. C is in-situ volume fraction; effective slip is required evidence for this slurry. Reject nonpositive required solids speed or C outside (0,1). Isolated settling is not automatically valid slip.
airlift_screen
isothermal_airlift		Pin = Pout + rho g depth;
W = Pout Qg_out ln(Pin/Pout);
Ql = eta W/(rho g lift)		 S3. Ideal isothermal gas and constant-density liquid; equal reservoir/outlet surface pressure. Gas rate is at outlet absolute pressure and the same temperature. Hydrostatic-equivalent injection pressure is assumed, not solved. Supplied eta includes all expansion-to-lift losses, not compressor efficiency. Reject zero lift, efficiency outside (0,1], or injection below submerged length. Returns pressure [Pa], gas power [W], and energy-limited liquid flow [m3/s]. No solids or deep-pressure nonideality; no hydraulic operating point.
slugging_screen
vertical_drift_flux		alpha = jg / (C0 (jg+jl) + Vgj) S4. Steady local upward gas/liquid fluxes; C0, drift, transition alpha and upper alpha all require calibration. Returns void fraction and bubble_indicated or slugging_possible. At transition equality, slugging is flagged. Above the calibrated maximum, classification is refused. No universal void-fraction cutoff, churn/annular prediction, solids extension or severe-riser-slugging stability result.
Table 2. Screening equations and scope. Density [kg/m3], length [m], viscosity [Pa s], velocity [m/s], acceleration [m/s2]; fractions and coefficients are dimensionless except drift [m/s].

Calibration conditions must identify geometry, inclination, phase properties, particle shape/size distribution, pressure and temperature. They are text evidence, not machine-verified physical facts. Changing those conditions requires a new qualified calibration. Passing an arbitrary broad range does not make a model applicable. These independent screens do not constitute a coupled three-phase model.

Verification and follow-up

The tests first establish missing-module failures, then check arithmetic, nonfinite and boolean input, signs, unit labels, field coverage, provenance, range/model mismatch and geometry/order errors. No physical performance result is claimed. Required follow-up includes sourced site/calibration inputs, case-specific environmental response, distributed string/pump definition, coupled three-phase transport, erosion, structural response and transient assessments. Packages 5 through 8 remain later work.
