Sample BSEE decline charts

Scope: BSEE decline charts. The sample will contain two API wells and field WR627. The full run and external explorer integration will await sample QA.

Resource intelligence

The implementation will reuse common.decline rate equations and the existing Julia OGOR-A extracts and source manifest. Existing decline APIs will remain compatible. New monthly analysis will retain elapsed calendar time, rather than compress filtered observations.

Method and artifact map

A monthly_dca module will validate OGOR-A records, sum oil volumes by API or field, divide by calendar days, retain zero-production months, and distinguish absent reports. Bounded least squares will compare exponential, hyperbolic and harmonic models by AIC. A continuous terminal exponential tail will impose a positive nominal minimum decline. Analytical integration will calculate remaining barrels from the last reporting boundary to the economic limit. Reported barrels will supply produced-to-date volume.

A monthly_dca_plots module will build date-based Plotly panels and static SVG/PNG from the same arrays. A sample builder will verify source digests and save arrays, compact metrics, output digests and an HTML page. Documentation will state units, fit windows, scenarios, source dates and limitations.

TDD and acceptance

Tests will precede implementation and cover a hand-calculated exponential recovery, terminal continuity, harmonic integration, calendar-day field sums, missing and shut-in months, invalid units and records, cap enforcement, forecast cutoff and independent withheld-history back-tests. The nearest decline tests will run with pytest through uv. The sample will be read back and static images will be inspected.

Adversarial plan review

Defect-hunting will challenge time compression, summed well-day normalization, volume/rate unit confusion, duplicate completion records, incomplete field reporting, economic-limit truncation, back-test leakage and false lifecycle EUR claims. Source hashes will be checked before consumption. Incomplete history will withhold EUR. Nonpositive limits or terminal decline will be rejected.

Risks and limits

Monthly calendar rates will include downtime. Operational changes may mimic reservoir decline. Field aggregation will not establish well-level recovery, boundary-dominated flow or unchanged well inventory. Economic limits will be explicit illustrative inputs; costs and income equality will not be established.
