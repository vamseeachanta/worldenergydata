# Petroleum Domain Reference

> Concise reference notes on core reservoir / petroleum-engineering concepts that
> support WorldEnergyData methodologies (volumetrics, economics, production).
> Last Updated: 2026-06-21

## Contents

- **[Reserves & Resources Classification](reserves-classification.md)** —
  1P/2P/3P, P90/P50/P10, contingent 1C/2C/3C; recoverable/commercial/uncertain
  criteria; economic metrics (cash flow, payout, NPV, IRR, economic limit).
  Aligned to SPE-PRMS.
- **[Well Performance: Productivity Index & IPR](well-performance-ipr.md)** —
  `q = PI·(Pr − Pwf)`, the IPR curve, linear-above / Vogel-below the bubble
  point, and the factors that shape inflow.
- **[Petrophysics Fundamentals](petrophysics-fundamentals.md)** — porosity
  (total/effective), permeability, φ–k crossplots, rock & fluid compressibility.

These are standard-knowledge primers (with authoritative references) intended to
ground the domain terminology used across the analysis modules; they do not
contain repository data.
