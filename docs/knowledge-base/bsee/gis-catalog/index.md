## Infrastructure Layers

### Platforms
- **Geometry**: Point
- **Features**: ~3,000+ offshore platforms
- **Attributes**: Area, Block, Structure Name, Water Depth, Install/Removal Date
- **Use Case**: Platform location mapping, infrastructure inventory

### Pipelines
- **Geometry**: Polyline (arcs)
- **Features**: ~10,000+ pipeline segments
- **Attributes**: Segment Number, Product Type, Status
- **Use Case**: Pipeline routing, network analysis

---

## Administrative Layers

### Blocks
- **Geometry**: Polygon
- **Features**: ~100,000+ OCS blocks
- **Attributes**: Area, Block Number, Protraction
- **Use Case**: Lease block reference, spatial queries

### Protraction Polygons
- **Geometry**: Polygon
- **Features**: ~60 protraction areas
- **Attributes**: Area Code, Area Name
- **Use Case**: Regional grouping, area reference

### Districts
- **Geometry**: Polygon
- **Features**: BSEE district boundaries
- **Attributes**: District Code, District Name
- **Use Case**: Regulatory jurisdiction

---

## Leasing Layers

### Active Lease Polygons
- **Geometry**: Polygon
- **Features**: Currently active OCS leases
- **Attributes**: Lease Number, Area, Block, Status
- **Use Case**: Current lease inventory, ownership analysis

### Unit Polygons
- **Geometry**: Polygon
- **Features**: Unitized areas
- **Attributes**: Unit Name, Lease Numbers
- **Use Case**: Unit agreement analysis

---

## Boundary Layers

### Fed/State Boundary
- **Geometry**: Polyline
- **Description**: Federal/State waters boundary (3 nautical miles)
- **Use Case**: Jurisdictional determination

### Continental Shelf Boundary
- **Geometry**: Polyline
- **Description**: Outer Continental Shelf boundary
- **Use Case**: OCS extent reference

### Planning Area Boundary
- **Geometry**: Polygon
- **Description**: OCS planning areas (Western, Central, Eastern GOA, etc.)
- **Use Case**: Regional planning, lease sales

### 8g Line
- **Geometry**: Polyline
- **Description**: Section 8(g) zone boundary
- **Use Case**: Revenue sharing determination

## Coordinate Systems

| Region | Datum | EPSG | Notes |
|--------|-------|------|-------|
| Gulf of America | NAD27 | 4267 | Primary datum for GOA |
| Alaska | NAD83 | 4269 | Standard for Alaska OCS |
| Pacific | NAD83 | 4269 | Standard for Pacific OCS |
| Atlantic | NAD83 | 4269 | Standard for Atlantic OCS |

### Projection Notes
- Shapefiles use geographic coordinates (lat/lon)
- Geodatabases may include projected versions
- Arc geometry uses straight-line segments (not true curves)

## File Format Details

### Shapefile (.shp)
- Multiple files per dataset (.shp, .shx, .dbf, .prj)
- Widely compatible
- Limited attribute field names (10 chars)

### File Geodatabase (.gdb)
- Single folder container
- Full attribute names
- Compatible with: ArcGIS, QGIS, FME, PostGIS
- Database types: File, Access, Oracle, SQL Server, PostgreSQL

## Download Script

### Python Example
```python
import requests
from pathlib import Path

GIS_DATASETS = [
    ("platform.zip", "Platforms"),
    ("ppl_arcs.zip", "Pipelines"),
    ("actlease.zip", "ActiveLeases"),
    ("blocks.zip", "Blocks"),
]

BASE_URL = "https://www.data.bsee.gov/Mapping/Files/"
OUTPUT_DIR = Path("./data/gis/bsee/")

for filename, name in GIS_DATASETS:
    url = BASE_URL + filename
    output_path = OUTPUT_DIR / filename
    response = requests.get(url)
    output_path.write_bytes(response.content)
    print(f"Downloaded: {name}")
```
