## URL Pattern Reference

### Raw Data Downloads
```
https://www.data.bsee.gov/{Category}/Files/{Dataset}RawData.zip
```

### Online Queries
```
https://www.data.bsee.gov/{Category}/{Dataset}/Default.aspx
```

### GIS Data
```
https://www.data.bsee.gov/Mapping/Files/{dataset}.zip          # Shapefile
https://www.data.bsee.gov/Mapping/Files/{Dataset}.gdb.zip      # Geodatabase
https://www.data.bsee.gov/Mapping/Files/{dataset}_meta.html    # Metadata
```
