## File Format Details

### General Format
- **Delimiter**: Pipe (`|`) for most files, comma (`,`) for some
- **Encoding**: ASCII
- **Line Endings**: Windows (CRLF)
- **Header Row**: Yes (first row contains column names)

### Common File Structure
```
COLUMN1|COLUMN2|COLUMN3|...
value1|value2|value3|...
value1|value2|value3|...
```

### Date Formats
- Most dates: `MM/DD/YYYY` or `YYYY-MM-DD`
- Some files: `YYYYMMDD` (no separators)

### Null Values
- Empty string (no value between delimiters)
- Some files use `NULL` or `N/A`

## Download Scripts

### Python Example
```python
import requests
import zipfile
from pathlib import Path

def download_bsee_data(dataset_url: str, output_dir: Path):
    """Download and extract BSEE raw data."""
    response = requests.get(dataset_url, stream=True)
    zip_path = output_dir / dataset_url.split('/')[-1]

    with open(zip_path, 'wb') as f:
        for chunk in response.iter_content(chunk_size=8192):
            f.write(chunk)

    with zipfile.ZipFile(zip_path, 'r') as zip_ref:
        zip_ref.extractall(output_dir)

    return zip_path

# Usage
download_bsee_data(
    "https://www.data.bsee.gov/Well/Files/APDRawData.zip",
    Path("./data/bsee/")
)
```

### Bash Example
```bash
#!/bin/bash
# Download BSEE well data
BASE_URL="https://www.data.bsee.gov"
OUTPUT_DIR="./data/bsee"

mkdir -p $OUTPUT_DIR

curl -o "$OUTPUT_DIR/APDRawData.zip" "$BASE_URL/Well/Files/APDRawData.zip"
unzip -o "$OUTPUT_DIR/APDRawData.zip" -d "$OUTPUT_DIR/"
```
