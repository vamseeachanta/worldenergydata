# Prompt Review Directory

This directory contains prompts and AI instructions for lead review and enhancement.

## Purpose

This folder is designated for collecting, organizing, and reviewing prompts used throughout the WorldEnergyData project to ensure they are optimized for AI assistance and collaboration.

## Structure

- **agent-prompts/**: AI agent-specific prompts
- **development-prompts/**: Development workflow prompts  
- **analysis-prompts/**: Data analysis and research prompts
- **review-notes/**: Lead review feedback and enhancement suggestions

## Review Process

1. Team members add prompts to appropriate subdirectories
2. Lead reviews prompts for clarity, effectiveness, and consistency
3. Enhanced prompts are documented with version history
4. Approved prompts are integrated into the main workflow

## Guidelines

- Include context and expected outcomes for each prompt
- Document any specific formatting or parameter requirements
- Note which AI models or tools the prompts are designed for
- Track performance and effectiveness of different prompt versions
