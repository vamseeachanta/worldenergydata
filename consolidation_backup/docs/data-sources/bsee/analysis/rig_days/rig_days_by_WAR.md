## By WAR Count

- Read all WAR (Well Activity Records) data. Each WAR has the following data
  - WAR_END_DT
  - WAR_START_DT
  - WAR_TYPE
  - RIG_NAME
  - WELL_ACTIVITY_CD and descripton
    - See, [cd and description](../../data/WELL_ACTIVITY_CD/well_activity_cd_description.md)
- Look at the start and end date and calculate the numnber of days
- Add all the days by WELL_ACTIVITY_CD

This is how we can calculate the rig days by WELL_ACTIVITY_CD.
